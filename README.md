# 🚗 Car Price Prediction

### 👩‍💻 Priyanka

> 🤖 Machine Learning project for predicting and classifying car prices using Python and Scikit-learn.

---

## ✨ About

This project applies **Machine Learning algorithms** to analyze car data and predict car prices or classify cars into **High Price** and **Low Price** categories.

## 🧠 Algorithms

| Algorithm                   | Purpose                      |
| --------------------------- | ---------------------------- |
| 📈 Linear Regression        | Predict car price            |
| 🌳 Decision Tree Regression | Predict car price            |
| 🎯 Logistic Regression      | Classify price as High / Low |

## 📊 Features Used

* 📅 **Year** — Car manufacturing year
* 🛣️ **Miles** — Distance travelled
* 🚘 **Name** — Car model/name
* 🎨 **Color** — Exterior/interior color
* 🔧 **Condition** — Car condition

The classification model uses One-Hot Encoding for categorical features and Standard Scaling for numerical features.
